If you think building an AI chatbot is hard, think again. I'm about to show you how I was able fake a surprisingly capable AI system using only free APIs, localStorage, and unholy prompt engineering. No paid APIs, no complex hosting solutions, no AI If you know basic javascript and some prompt engineering, you're good to go. 

Let's cook.

## The Basics

The AI LLM API I'll be using is `deepseek/deepseek-r1-0528:free` from [openrouter.ai](https://openrouter.ai/deepseek/deepseek-r1-0528:free) - It's basically the best AI model you can use indefinately for free, though I did discover that it can have timeout issues when hosting your application on platforms like Vercel and Netlify. Still, try it first, develop with it, and if you run into timeout issues you can't fix, swap in another, smaller, and faster model like `arcee-ai/trinity-mini:free` or `xiaomi/mimo-v2-flash` and it should work just the same. To get started using Openrouter, you need to first create a free account and then [create an API key](https://openrouter.ai/settings/keys).

My original plan was to try doing this with only HTML and Vanilla Javascript, but it turns out that OpenRouter API is not meant to be called directly from client-side JS in a browser, so when I tried calling it with a fetch function, I ran into a `net::ERR_NAME_NOT_RESOLVED` error. So sad. This means that the very least I can do is create a NextJS app. If you're not familiar with NextJS, this post may still be useful, and I'll try to explain the reasoning behind what I do so its clear that this method isn't framework-specific.

To create a nextJS app, I ran the following command in the terminal and selected all the defaults:

```
npx create-next-app@latest aichatbot
```
